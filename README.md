# 🎯 Problem Statement

Traditional e-commerce platforms require users to perform multiple steps:

1. Search for products
2. Apply filters
3. Compare prices
4. Read product information
5. Decide which products are relevant
6. Add products to the cart

This process can be time-consuming and overwhelming, especially when users have a specific **budget and goal**.

### Example

Instead of searching:

> Laptop → Keyboard → Mouse → Headphones → Desk accessories

A user can simply say:

> **"Build me a college setup under ₹15,000."**

ShopPilot AI processes this goal and recommends relevant products.
